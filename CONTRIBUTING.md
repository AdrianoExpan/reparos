# Contribuindo para Reparos

Obrigado por considerar contribuir para o projeto **Reparos**! Este é um repositório comunitário para consulta de informações técnicas sobre reparos EXPAN.

## Como contribuir

### 1. Reportar Bugs
Se encontrou um erro na documentação ou informação técnica:
- Abra uma [issue](https://github.com/AdrianoExpan/reparos/issues)
- Descreva o problema de forma clara
- Forneça exemplos se possível

### 2. Sugerir Melhorias
- Abra uma [discussion](https://github.com/AdrianoExpan/reparos/discussions)
- Descreva sua ideia e o benefício que traria

### 3. Enviar Conteúdo
1. Faça um fork do repositório
2. Crie uma branch para sua contribuição: `git checkout -b feature/meu-guia`
3. Adicione o conteúdo em Markdown na estrutura apropriada:
   - `/docs/guias/` para guias de procedimento
   - `/docs/tutoriais/` para tutoriais passo a passo
   - `/docs/faq/` para perguntas frequentes
   - `/exemplos/` para exemplos práticos
4. Commit suas mudanças: `git commit -m "Adiciona guia sobre..."`
5. Push para a branch: `git push origin feature/meu-guia`
6. Abra um Pull Request

## Diretrizes de Conteúdo

- Mantenha a linguagem clara e técnica
- Use títulos descritivos (H2 ou H3)
- Inclua exemplos quando possível
- Revise a ortografia e gramática
- Forneça contexto e referências

## Estrutura de Contribuição

```
Tipo de arquivo         | Localização
-----------------------|--------------------------------
Guias de procedimento   | /docs/guias/
Tutoriais passo a passo | /docs/tutoriais/
Perguntas frequentes    | /docs/faq/
Exemplos práticos       | /exemplos/
Documentação geral      | /docs/
```

## Código de Conduta

Seja respeitoso e profissional em todas as interações.
