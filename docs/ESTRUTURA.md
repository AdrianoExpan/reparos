# Estrutura do Repositório Reparos

## Visão Geral

Este repositório contém informações técnicas e documentação sobre reparos EXPAN, organizadas de forma clara e acessível.

## Diretórios

### `/docs`
Documentação principal do projeto.

- **`/guias`** - Guias de procedimento e como fazer
  - Passo a passo para reparos específicos
  - Procedimentos técnicos
  - Boas práticas

- **`/tutoriais`** - Tutoriais em profundidade
  - Guias educacionais completos
  - Explicações detalhadas
  - Exemplos prático

- **`/faq`** - Perguntas Frequentes
  - Respostas rápidas para dúvidas comuns
  - Troubleshooting
  - Dicas úteis

### `/exemplos`
Exemplos práticos, código de exemplo, ou configurações de referência.

### `/templates`
Templates e modelos reutilizáveis para documentação.

## Como Navegar

1. **Procurando um guia rápido?** → Veja `/docs/guias/`
2. **Quer aprender mais a fundo?** → Consulte `/docs/tutoriais/`
3. **Tem uma pergunta comum?** → Procure em `/docs/faq/`
4. **Precisa de um exemplo?** → Acesse `/exemplos/`
